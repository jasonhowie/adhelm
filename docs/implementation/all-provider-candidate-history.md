# All-provider candidate history

Development implementation, not live-provider or release evidence.

The six fixed native preview commands accept optional `--retain`. LinkedIn,
Reddit and TikTok join the existing OpenAI, Meta and Google candidate union in
schema version 1. Existing variant serialization and content digests remain
unchanged; retained rows continue through the canonical JSONL append and verified
read path. `schema candidate-record --root-only` exposes the complete provider
discriminator within bounded output; definition selection supplies further detail.

Each new variant retains the typed compiler review, planning boundary, canonical
creative references, input/spec digests and exact maximum spend. LinkedIn stores
its group total budget as a two-decimal USD string, Reddit preserves integer
lifetime-spend micros, and TikTok stores the ad-group total as a two-decimal USD
string. Validation independently checks those amounts against canonical integer
minor units, validates distinct role handles, and cross-checks account, campaign,
creative and spec identity. Original briefs, copy, destinations, native media or
identity IDs, and replayable native request bodies are absent from these records.

Retention creates `CANDIDATE_COMPILED` evidence only. Its compact receipt needs
no sharing key or provider credential and is sized before append. Uncertain
local persistence returns an explicit diagnostic directing verified history
inspection before another attempt. Catalog/show and exports use verified ledger
checkpoints; local identifiers and role handles are pseudonymized before sharing.
Critical requirements are never dropped to fit a review into a small output bound.

LinkedIn remains draft, Reddit paused, and TikTok disabled. All variants remain
`OFFLINE_CANDIDATE_NOT_EXECUTABLE` with fixture-only compiler evidence. Retention
does not satisfy current account, access, targeting, ownership, creative,
conversion, drift or authorization checks. In particular, TikTok's declared
video metadata remains `DECLARED_UNVERIFIED_NO_LOCAL_DECODE`; no asset, rendition,
analysis, deployment or media-verification record is manufactured by retention.

Regression checks cover six-provider catalog/show, retention/reload, strict
scalar types, recomputed invalid candidate hashes, exact native spend, invalid
source declarations, privacy, small output bounds and compatibility digests
generated from the exact M13 archive. Broader development validation is recorded
separately only after it runs against a committed source archive.
