# Meta campaign PAUSE approval protocol

Status: implementing. This slice defines one closed Python receipt subject for
an already retained M40 Meta campaign PAUSE plan. It has no execution path.

`META_CAMPAIGN_PAUSE_PLAN` binds the full, strictly reconstructed M40 action,
the exact plan and subplan digests, a bounded challenge lifetime, grantor
reference, nonce, and the configured approval-host metadata. The receipt wire
uses the existing v1 P-256 signature payload. Python verifies an independently
provided public-key pin and produces typed receipt facts; it does not enroll a
pin, consume a receipt, issue a provider authorization, or claim a remote
effect.

The native-review projection shows the local workspace/profile/application
association, stable Meta account and campaign references, the observed
configured/effective campaign statuses, the bounded read interval, the
`ACTIVE` to configuration-only `PAUSED` transition, egress, zero incremental
spend, recovery requirement, and all no-authority limitations. It excludes
the credential-binding reference, derived principal, configuration/profile
digests, tokens, request bodies, raw provider data, and outcome claims. The
postcondition explicitly says effective delivery is `NOT_PREDICTED`.

The checked-in whole-second and nonzero-six-fraction fixtures are generated by
[`generate_meta_pause_approval_vectors.py`](../../native/macos-approval-host/Tests/ApprovalHostCoreTests/Fixtures/MetaPause/generate_meta_pause_approval_vectors.py).
They contain only synthetic canonical challenge, review, and unsigned receipt
data. The fractional fixture uses `.123456Z` for every M40 action timestamp;
its receipt issue timestamp remains the distinct v1 three-digit form. Neither
fixture has a private key, signature, OS authentication result, native host
operation, or provider result.

Receipt acceptance remains a separate local-history boundary: it must load the
named retained Meta PAUSE plan and compare the complete canonical action before
claiming the receipt. Existing bridge-v1 direct-plan allowlists intentionally
remain OpenAI PAUSE and GA4 CREATE only; this subject cannot reach the installed
native bridge, an execution command, a Graph request, or a provider mutation.
